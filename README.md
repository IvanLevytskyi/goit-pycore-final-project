# goit-pycore-final-project

# 📑 Персональний Помічник (CLI Assistant)

Ця програма — консольний персональний асистент, який допомагає ефективно керувати контактами (Адресною Книгою) та текстовими нотатками. Програма автоматично зберігає всі дані на жорсткому диску у вашій домашній директорії, тому ви можете перезапускати її без втрати інформації.

---

## 🚀 Встановлення та запуск

### 1. Передумови

Для роботи застосунку на вашому комп'ютері має бути встановлений **Python 3.8** або новішої версії. Перевірити версію можна командою:

```bash
python --version

```

### 2. Клонування репозиторію

Склонуйте цей репозиторій на свій комп'ютер та перейдіть у робочу директорію:

```bash
git clone https://github.com/IvanLevytskyi/goit-pycore-hw-08.git
cd goit-pycore-hw-08

```

### 3. Запуск застосунку

Програма використовує виключно вбудовані бібліотеки Python (`pickle`, `re`, `pathlib`), тому встановлювати додаткові сторонні пакети (pip) не потрібно.

Запустіть головний файл програми:

```bash
python main.py

```

---

## 💾 Зберігання даних

Всі дані автоматично серіалізуються та записуються на жорсткий диск у папку поточного користувача операційної системи.

* **Шлях до файлів:** `~/.assistant_data/` (наприклад, `C:\Users\Username\.assistant_data` на Windows або `/Users/Username/.assistant_data` на macOS).
* **Файли збереження:** `address_book.pkl` (контакти) та `notes.pkl` (нотатки).
* **Синхронізація:** Дані автоматично завантажуються під час старту програми та надійно зберігаються при коректному виході за допомогою команд `exit` або `close`.

---

## 💻 Інструкція з використання (Команди)

Після запуску програма очікує на введення команд. Для отримання повного списку безпосередньо в консолі введіть `help`.

### 📇 Управління контактами

1. **Створення нового контакту:**
```
add-contact [Ім'я]

```


*Приклад:* `add-contact Denys` — створює порожній запис для Дениса.
2. **Додавання телефону (з валідацією на 10 цифр):**
```
add-phone [Ім'я] [10 цифр номера]

```


*Приклад:* `add-phone Denys 0931234567`
3. **Додавання Email (з валідацією формату):**
```
add-email [Ім'я] [електронна_пошта]

```


*Приклад:* `add-email Denys denys@gmail.com`
4. **Додавання дня народження:**
```
add-birthday [Ім'я] [ДД.ММ.РРРР]

```


*Приклад:* `add-birthday Denys 24.08.1995`
5. **Додавання адреси проживання:**
```
add-address [Ім'я] [текст адреси]

```


*Приклад:* `add-address Denys Kyiv, Khreschatyk St, 1`
6. **Редагування номера телефону:**
```
edit-phone [Ім'я] [старий_номер] [новий_номер]

```


*Приклад:* `edit-phone Denys 0931234567 0507654321`
7. **Пошук та перегляд контакту:**
```
search-contact [Ім'я]

```


8. **Видалення контакту:**
```
delete-contact [Ім'я]

```


9. **Показати всі контакти:**
```
all-contacts

```


10. **Перегляд найближчих днів народження:**
```
birthdays [кількість_днів]

```


*Приклад:* `birthdays 7` або просто `birthdays` (за замовчуванням покаже на 7 днів уперед). Функція автоматично переносить дату привітання на понеділок, якщо день народження припадає на суботу чи неділю.

---

### 📝 Управління нотатками

1. **Додати нову нотатку:**
```
add-note [Заголовок] [Текст вашої нотатки]

```


*Приклад:* `add-note Shopping Купити молоко, хліб, сир`
2. **Редагувати існуючу нотатку:**
```
edit-note [Заголовок] [Новий текст нотатки]

```


*Приклад:* `edit-note Shopping Купити тільки каву і фрукти`
3. **Пошук нотаток (за ключовим словом):**
Шукає збіги як у заголовках, так і всередині тексту нотаток.
```
search-note [Ключове_слово]

```


*Приклад:* `search-note каву`
4. **Видалити нотатку:**
```
delete-note [Заголовок]

```


5. **Показати всі нотатки:**
```
all-notes

```

### 🛑 Завершення роботи

Щоб зберегти всі внесені зміни та безпечно закрити помічника, використовуйте одну з команд:

* `exit`
* `close`

> ⚠️ **Важливо:** Не закривайте вікно терміналу примусово (через хрестик) під час активної сесії, оскільки дані зберігаються саме в момент виконання команди виходу.
